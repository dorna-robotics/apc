# LCR Meter Startup

## 1. Power on
Press the **Power** button in the top-left corner.

## 2. Enter the configuration menu
Hold **UTIL** for 3 seconds. The screen shows **bEEP**.

## 3. Turn off the beep
Press **Down**. The **on** at the top of the screen changes to **oFF**. The meter will no longer beep while reading.

## 4. Turn off auto sleep
Press **UTIL** once. The screen shows **AoFF**.

Press **Down**. The **5** at the top (5 minutes) changes to **oFF**. The meter will now stay on indefinitely and will not shut off mid-cycle.

## 5. Return to the main screen
Press **L/C/R/Z**.

## 6. Confirm capacitance mode
Check for **C** in the top-left corner of the screen. If it is not there, press **L/C/R/Z** to cycle through modes until **C** appears.

## 7. Enable USB
Press **USB**. **RMT** flashes in the bottom-right corner when USB is active. The meter can now be read over USB.

---

## Quick reference

| Step | Button | Screen shows |
|---|---|---|
| Power on | Power (top left) | Display on |
| Config menu | Hold UTIL 3 s | bEEP |
| Beep off | Down | on → oFF |
| Auto sleep menu | UTIL | AoFF |
| Auto sleep off | Down | 5 → oFF |
| Main screen | L/C/R/Z | Measurement screen |
| Capacitance | L/C/R/Z (if needed) | C top left |
| USB on | USB | RMT flashing bottom right |
